# Yearbook Flip
1. `npm install`
2. Salin `.env.example` → `.env`, isi URL & anon key Supabase
3. Supabase > SQL Editor: jalankan `supabase.sql`; buat user admin di Authentication > Users
4. `npm run dev` — buku di `/`, admin di `/#/admin`
Elemen dekorasi: cari komentar `SLOT` di `src/Yearbook.jsx`.
